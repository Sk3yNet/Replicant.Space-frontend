Simulations

Timed scenarios run in a datacenter's replicant interface ({{ loc }}). Queue a run and logistics brings the compute cores (spare ones pinned there, else printed and delivered) and a free replicant to the interface; when both are there the bell says so (again every 2 h) and you start it here. The bootstrap logic plays the run, recording when each step of its build order was reached. When the run ends, everything from inside it is discarded: only the report stays, and the next run's build order learns from it.
