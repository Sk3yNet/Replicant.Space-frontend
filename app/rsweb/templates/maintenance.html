Upkeep

{% with ids="maintenance" %}{% include "partials/rules_slot.html" %}{% endwith %}

Devices wear down with use. A maintenance drone repairs only while on the patrol directive: it takes the most worn device in its system back to 100 %, then the next. Vessels that can print self-repair below 30 % (1 %/h). Rule Keep maintenance drones patrolling is {{ 'on' if cfg.enabled else 'off' }} · worn below {{ cfg.threshold }} % · critical below {{ cfg.critical }} % · print missing drones {{ 'on' if cfg.print_missing else 'off' }}.

Hub upkeep

A hub draws its upkeep from the stockpile at its own location, and only with a maintenance drone patrolling its system. The game prices it per 20 % of capacity; the target is enough to bring the hub back to 100 % plus {{ spare_steps }} more step. Logistics delivery is {{ 'on' if hub_upkeep else 'off' }} (rule option Logistics stocks hub upkeep).
