Set up your Replicant Space server

Welcome, {{ user }}. You get your own copy of this client: it holds your game API key on the server (never in your browser), keeps your full event history and runs your automations around the clock. It takes three steps and about five minutes.

{% if full %}
This server already hosts as many users as its owner allows. Ask them to raise MAX_TENANTS.
{% endif %}

  1. Create a game account

    Replicant Space is played through its API, so an account is just an email, a name and a time zone. Fill this in and the game emails you a link. (Rate-limited by the game to a few sign-ups an hour.)

    Rather do it yourself?

    Any HTTP tool works, for example:

    curl -X POST {{ api_base }}/accounts \
  -H 'Content-Type: application/json' \
  -d '{"email": "you@example.com", "name": "Bob", "timezone": "Europe/London"}'

    Already have an account? Skip to step 3 if you have your key, or get a new key if you've lost it.

  2. Open the email and copy your API key

    Look for the email from Replicant Space{% if form.email %} at {{ form.email }}{% endif %} (check spam too) and click its link. The page that opens shows a short message like this:

    {
  "api_token": "OsiJIqbw_8tj4SLgeo_…",
  "message": "Email verified successfully",
  "replicant": { "name": "bob-1", "replicant_code": "C2AF4A82" }
}

    Copy the value of api_token: the text between the quotes, without the quotes. That's your API key. Keep it somewhere safe, like a password manager. It's the only key to your account.

    The link works once. If it says the link has expired or was used, request a new key below.

  3. Paste the key here

    The key is checked with the game first (GET /accounts/me), then stored on this server only. It's never sent to your browser or shown again. Then your server starts and the dashboard opens; it fills in over the first minute.
